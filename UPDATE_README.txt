RTK Education CRM — v10 Documents Workspace

Распакуйте архив в корень проекта с заменой файлов.
Версия кумулятивная: содержит изменения v8/v9 и новый документооборот v10.

Что добавлено в v10:
- отдельная страница DocumentsPage вместо демо-списка;
- реестр документов с поиском и фильтрами по статусу, категории и вузу;
- KPI: всего / на согласовании / готово / требуют правок;
- загрузка документа с привязкой к вузу и программе;
- категории документов и четыре статуса согласования;
- карточка документа: статус, категория, программа, ответственный, комментарий;
- создание новой версии;
- удаление документа;
- переход из документа в карточку вуза/программы;
- адаптивная мобильная версия;
- документы перенесены в ApiClient + mockApi;
- операции с документами добавляют события в ленту активности.

Демо-ограничение:
реальные байты загруженного файла не отправляются на сервер; в mock API сохраняются метаданные.
При подключении C# backend интерфейс можно оставить тем же, заменив адаптер API.
