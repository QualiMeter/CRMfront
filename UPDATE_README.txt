CRM frontend v11 — analytics dashboard

Распакуйте архив в корень проекта с заменой файлов.
База: v10 documents workspace.

Что добавлено:
- отдельная страница аналитики вместо старого компактного блока;
- фильтр аналитики по вузу;
- KPI: заявки, обучающиеся, средний спрос, прогресс;
- рейтинг программ по востребованности;
- агрегирование спроса по ИТ-продуктам;
- воронка прохождения всех 14 этапов;
- распределение статусов workflow;
- блок операционных рисков (просрочки, blocked-этапы, документы с правками, низкий прогресс);
- сравнение вузов с переходом в карточку;
- переходы из рисков к задачам/документам;
- адаптация аналитики под планшеты и мобильные экраны.

Новых зависимостей нет: графики собраны на React + CSS.
Маркер сборки в index.html: v11-analytics-dashboard.
