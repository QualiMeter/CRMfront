CRM frontend v13 — stage attachments

Распакуйте архив в корень проекта с заменой файлов.
База: v12 reports workspace.

Что добавлено:
- вложения непосредственно в выбранном этапе workflow;
- форматы из ТЗ: PNG, JPEG, PDF, ZIP, GZIP, RAR, DOC, DOCX, XLS и XLSX;
- ограничение размера файла 25 МБ и понятные ошибки валидации;
- имя, размер, автор и время загрузки файла;
- скачивание вложения;
- удаление только после подтверждения;
- события загрузки и удаления в активности вуза;
- адаптация списка вложений для мобильных экранов;
- методы mock API, повторяющие будущий контракт backend.

Важно: в mock-режиме файл существует до перезагрузки вкладки. После подключения backend загрузка должна выполняться multipart-запросом, а файл храниться в объектном или файловом хранилище.

Проверено: npm run build, npm audit --omit=dev.
