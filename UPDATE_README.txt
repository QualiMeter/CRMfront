CRM frontend v14 — Excel import

Распакуйте архив в корень проекта с заменой файлов.
База: v13 stage attachments.

Что добавлено:
- отдельный раздел «Импорт» в настольной и мобильной навигации;
- чтение XLS и XLSX до 20 МБ;
- переключение листов Excel-книги;
- импорт вузов и программ/ИТ-продуктов;
- автоматическое сопоставление типовых русских заголовков;
- ручное сопоставление всех колонок;
- обязательные и необязательные поля;
- предпросмотр до 50 строк;
- построчная проверка значений;
- поиск неизвестных вузов и дублей;
- пропуск строк с ошибками;
- добавление корректных строк через mock API;
- адаптивная версия мастера импорта.

Новая зависимость: @e965/xlsx. Парсер загружается лениво только после выбора файла.

Проверено: XLS, XLSX, npm run build, npm audit --omit=dev.
