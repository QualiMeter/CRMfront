CRM frontend v12 — reports workspace

Распакуйте архив в корень проекта с заменой файлов.
База: актуальный main/v11 analytics dashboard.

Что добавлено:
- отдельный раздел «Отчеты» в основной и мобильной навигации;
- фильтры по периоду, вузу, ИТ-направлению, ИТ-продукту и ответственному;
- выбор колонок отчета;
- интерактивный предпросмотр с переходом в карточку программы;
- настоящая выгрузка XLSX;
- выгрузка PDF с поддержкой русского текста;
- адаптация страницы отчетов для планшетов и телефонов;
- ленивое подключение библиотек экспорта, чтобы не замедлять начальную загрузку CRM.

Новые зависимости: fflate, pdfmake, @types/pdfmake.
Проверено: npm run build.
